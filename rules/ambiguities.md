# 마마모 규칙의 미확정 사항

후속 엔진 검증: 기존 A01–A31의 resolved 표시는 각 승인 문구에만 해당하며 모든 하위 필드가 결정되었다는 뜻이 아니다. 추가 승인 E01–E05는 engine-resolutions.yaml에 기록했고, 남은 B01–B03은 engine-preflight-report.md에 질문과 권장안을 기록했다. 아래의 전면 해소 표현은 후속 검증 결과로 정정한다.

40쪽을 모두 시각 검토한 뒤 남은 31건이다. 아래 A/B는 가능한 해석이며 채택된 규칙이 아니다. 권장 해석 역시 사용자 확인 전 적용하지 않는다. 사용자 확인으로 31건 모두 해소되었다. 원문은 문장 전체를 전재하지 않고 정확한 요약으로 기록했다. PDF 쪽수는 1부터 센다.

국제역 채택(A02), 중복·복합역만(A04), 부(A05), 특수 화료형(A15), 점수표(A30–A31)는 특히 넓은 범위의 문제 생성을 막는다. 사용자 요청에 따라 이 상태에서는 웹게임 구현을 시작하지 않는다.
