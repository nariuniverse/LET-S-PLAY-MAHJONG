검증 상태: BLOCKED_BY_ENGINE_PREFLIGHT

후속 검증: [engine-preflight-report.md](engine-preflight-report.md). E01–E05는 추가 승인되어 engine-resolutions.yaml에 기록했다. 실제 엔진 판정에 필요한 B01–B03은 미결정이다. 아래 기존 통계와 PDF 검토 기록은 유지하지만, 기존의 전면 해소/구현 가능 판단은 이 후속 결과로 정정한다.

## PDF 점검

- 대상: docs/mamamo.pdf
- 전체 페이지: 40쪽
- 시각 검토: 40쪽 모두 완료
- PDF 3쪽부터 인쇄 01쪽, PDF 40쪽이 인쇄 38쪽이며 PDF 1–2쪽은 인쇄 번호 없음
- 전 페이지 텍스트 레이어 0자: 스캔 이미지 기반
- OCR 사용: 없음. 렌더링 이미지를 직접 시각 전사·대조
- 부 계산표: PDF 37쪽 / 인쇄 35쪽
- 점수표: PDF 38쪽 / 인쇄 36쪽
- 판독 제한: 점수표 자 50부 쯔모 6셀의 행 순서가 후보 공식과 충돌했으나, 승인된 A30/A31 해석으로 계산 정책을 확정함

## 통계

- 마마모 정책 규칙: 50개
- 마마모 역: 76개
- 마마모 역만 배수 항목: 28개
- 예시 패 레코드: 72개(정규화 문자열 70개, rank-only 2개)
- 완성패 예시: 59개(일반 골격 56개, 특수 형태 3개)
- 점수표: 숫자 셀 120개, 병합 만관 영역 10개
- 표준 정책 규칙: 20개
- 표준 역: 41개(역만 12개)
- 비교표: 45개(동일 12, 차이 22, 해소된 기존 미확인 11)
- 사용자 확인 완료 모호성: 31개(A01–A31). 승인 해석은 mamamo-rules.yaml resolutions에 기록.

## 검증

- mamamo-rules.yaml: YAML 문법 통과
- standard-riichi-rules.yaml: YAML 문법 통과
- schema.yaml, pdf-review.yaml: YAML 문법 통과
- 두 규칙 세트는 ruleSet을 명시하고 상속하지 않음
- 주요 정책·역에 sourcePages와 confidence가 있음
- 마마모 원문 값과 승인된 해석을 분리 보존했으며, 승인 해석은 resolutions A01–A31로 명시함

## 이전 구현 차단 사항과 해소 상태

implementationAllowed: false. 엔진 구현 권한은 승인되었지만 의미 검증에서 B01–B03 누락이 확인되어 구현 진행을 중지한다. 이 값은 현재 진행 가능 상태이며 사용자 승인 여부와 다르다. 웹 UI는 승인되지 않았다.
