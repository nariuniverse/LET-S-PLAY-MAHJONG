# 최적 타패 레벨 — 2026-09-23

최적 타패 화면 상단에서 레벨 1·2·3을 선택한다. 선택 즉시 해당 레벨의 새 문제를 만들고 타이머와 답안을 초기화한다. 다음 문제, 규칙 전환, 다른 연습에서 돌아오기에도 선택한 레벨을 유지한다.

| 레벨 | 화면 이름 | 출제 기준 |
|---|---|---|
| 1 | 기초 | 기존 v1 생성기를 유지. 기본적인 패 연결·샹텐·유효패 연습 |
| 2 | 비교 | 최선의 타패 후 1~2샹텐, 같은 최소 샹텐 후보 3종 이상, 최선과 다음 비정답 후보의 유효패 차이 4장 이상 |
| 3 | 심화 | 최선의 타패 후 1~2샹텐, 같은 최소 샹텐 후보 4종 이상, 최선과 다음 비정답 후보의 유효패 차이 1~2장 |

레벨 2·3은 단독 고립패를 제외하고 정답 패 종류를 최대 2종으로 제한한다. 고립패는 같은 패가 없고 같은 수패의 ±1·2 이내 연결도 없는 패다. 같은 샹텐·같은 유효패 장수의 공동 최적은 모두 정답이다. 정답 기준은 기존 엔진의 ‘최소 샹텐 → 최대 유효패 장수’를 그대로 사용한다. 타점·수비 판단까지 포함하는 난이도는 아니다.

## 문제 생성과 재현

- `src/practice/discard-patterns.ts`: 레벨 2·3 각각 20개 기본 형태. 표준·마마모 두 규칙에서 난이도 조건을 검증했다.
- 시드로 기본 형태·수패 배치·각 수패의 숫자 반전(1↔9)을 선택한다. 기본 형태마다 최대 24가지 배치가 가능하다. 현재 고급 문제는 검증된 두 수패 형태를 변형하는 방식이며 무한히 새로운 형태를 생성하는 방식은 아니다.
- 매 문제의 최종 손패를 선택한 규칙 엔진으로 다시 분석하고 난이도 조건을 재확인한다. 조건에 맞지 않으면 다른 기본 형태를 확인하며 쉬운 문제로 대체하지 않는다.
- `generateDiscard(seed, context, level = 1)`. 레벨 1은 기존 ID·시드·v1 생성 순서를 유지한다. 레벨 2·3은 레벨이 포함된 v2 ID를 쓴다.
- URL의 `level=1|2|3`을 저장한다. 레벨이 없는 기존 URL이나 잘못된 레벨 값은 1로 연다. 같은 규칙·레벨·문제 번호는 같은 문제로 재현된다.
- 기존 학습 기록은 레벨 1로 집계한다. 새로운 타패 기록에는 레벨을 저장하며 통계는 규칙·연습·레벨별로 구분한다. 전체 최근 200개 제한과 동일 문제 ID 재풀이 중복 방지는 유지한다.
- 레벨 2·3의 해설에서 최소 샹텐 후보 수와 최선/다음 후보의 유효패 차이를 보여 준다.
